# SESPy user manual, screenshot refresh and About modal — design

**Date:** 2026-09-05 · **Target release:** v1.8.0 · **Status:** approved in chat (four scoping answers), executing.

## Problem

- The About modal (`sespy/modules/topbar_actions.py:_about_modal`) renders the whole README (developer-facing, half release notes) and the whole CHANGELOG. Its screenshots are broken in-app because only the empty `www/` directory is served as static assets (`app.py:314`).
- The ten `docs/screenshots/*.png` date from 2026-06-25 (v1.0/v1.1) and predate v1.3–v1.7; nothing regenerates them.
- There is no user manual. In-app help is one translated paragraph plus three per-panel explainer blocks. The scientific background and the literature that shaped v1.0–v1.7 exist only in specs, docstrings and the weekly alerts.

## Decisions (user-approved)

1. Manual lives at `docs/MANUAL.md`, rendered as a **Manual** tab in the About modal and readable on GitHub. Overview becomes a curated summary.
2. Screenshots are regenerated by a dedicated Playwright script, `tests/make_docs_screenshots.py`, not promoted from the e2e run.
3. Manual text is English only; About tab labels stay translated in all nine languages.
4. References cover everything: method foundations and every literature-alert paper that produced a shipped feature. Foundation citations are verified via scite before inclusion.

Known limitations to state plainly (from the panel survey): Simplify Network is preview-only; BOT series are session-only; Recent Projects records the upload's temporary path and is populated only by Load Project; Boolean attractor search is hard-capped at 12 nodes (the sample has 17); PDF export needs WeasyPrint; the report omits stakeholders, quadrant, Boolean, simulation and BOT results.

## Screenshot script (`tests/make_docs_screenshots.py`)

- Standalone Playwright script (same shape as the e2e scripts): boots nothing itself; expects a server on `--port` (default 8000) and the sample project. Viewport 1280×900, light theme, English.
- For each of the 19 panels: navigate via the nav, wait for the panel's main output, screenshot to `docs/screenshots/<nav value>.png`. Button-gated blocks are triggered first: Loop Analysis "Detect loops"; Metrics "Run cascade analysis", "Trace paths", "Detect subsystem modules"; Boolean "Run analysis"; Simulation "Run simulation" (loop dominance on) and "Run Monte Carlo"; Intervention "Run simulation" with one ablated node.
- Extra state shots: `metrics_cascade.png` (scrolled to the cascade block), `simulation_montecarlo.png`, `about_manual.png`.
- Old file names `qsem_import.png` and `rate_connections.png` are removed; README's screenshot table is rewritten to the new names.
- Not part of the e2e gate (slow, writes into the repo). Documented in README "Test it" as the per-release refresh step.

## About modal and static assets

- `app.py`: `static_assets={"/": WWW, "/docs/screenshots": ROOT / "docs" / "screenshots"}` so the manual's relative image paths (`docs/screenshots/x.png`) resolve in-app and on GitHub.
- `_about_modal`: tabs Overview · Manual · Changelog. Overview = version header + a short curated markdown block (what it is, the six workflow stages, the 19 panels in a table, where the manual is, licence). Manual = `ui.markdown(read_project_doc("docs/MANUAL.md"))`. Changelog unchanged.
- `_help_modal`: keeps `help.body`; adds one translated line `help.manual_hint` pointing to About → Manual.
- New i18n keys in nine languages: `about.manual`, `help.manual_hint`.
- `deploy/deploy.sh`: also ships `docs/MANUAL.md` and `docs/screenshots/` (staged under `docs/`).

## Tests

- `tests/test_manual.py` (unit): manual exists and is non-trivial; every `docs/screenshots/*.png` referenced in MANUAL.md and README.md exists; every nav label from `app.NAV` appears as a Part II heading; every `doi:` string in `sespy/network.py` and `sespy/dynamics.py` appears in Part IV; the version line matches `sespy.__version__`.
- `tests/test_i18n.py`: the two new keys present in all languages.
- `tests/test_topbar_e2e.py` (existing About coverage) extended: open About, click the Manual tab, assert a Part II heading is visible and the first `<img>` inside the modal has `naturalWidth > 0`.

## Review (user-requested workflows)

1. **Manual fact-check workflow**: per-part reviewer agents compare every claim about controls, labels, outputs and formulas against the code; every finding is adversarially verified by two refuters; confirmed findings are fixed.
2. **Code review workflow** over the About/static-assets/deploy/screenshot-script diff, same shape.

## Out of scope

Translating the manual; a chart on the cascade block; changing any analysis behaviour.
