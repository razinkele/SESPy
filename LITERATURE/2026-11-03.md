## Implications for SESPy

**Chalchisa et al. (PLOS ONE 2026)** is the most directly on-topic paper this week. Its methodology closely mirrors SESPy's use case: participatory data collection → CLD construction → loop classification (R/B) → leverage intervention identification. Key data points:

- The study constructs four distinct CLDs for four coexisting farming systems within the same landscape. SESPy currently treats a single CLD per session. The multi-CLD comparison pattern (same node vocabulary, different causal structures) could eventually motivate a multi-graph comparison feature, but this is speculative — the current single-graph model covers the paper's analytical method completely.
- The paper follows Sterman's four-phase CLD construction protocol and uses qualitative interviews + FGD as the data source — identical to SESPy's target user workflow.
- Loop detection, R/B classification, and leverage-point identification are all shipped features in SESPy. **This paper validates existing functionality**.
- No novel algorithm is introduced; the paper is applied modelling, not methodological innovation.
- **Non-actionable**: no new issue warranted.

**CL-DIY (Zenodo 2026)** highlights an emerging software niche for browser-based CLD tools. SESPy is a Shiny app with a Python backend; CL-DIY is a browser editor. They are complementary (CL-DIY for building CLDs, SESPy for analysing them) but overlap in basic drawing/storage. No algorithmic contribution; non-actionable.
