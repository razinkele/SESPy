## Implications for SESPy

**D2D (key paper).** Does exactly what SESPy sits between: takes a causal loop diagram, derives dynamics, and ranks leverage points *while propagating uncertainty*. SESPy already has the components separately — `feedback_loops`/`loop_polarity`/`classify_loops`, the `leverage_scores` composite (z(betweenness)+z(eigenvector)+z(PageRank)), Monte Carlo in the dynamic-simulation module, and an edge `confidence`/`strength` column — but they are not yet wired so that edge-confidence uncertainty flows into leverage scores and loop classification. Strong validation of the architecture; clear extension.

**Dianchi Lake.** Introduces a social-ecological "fit" diagnostic (alignment of social ties vs. ecological interdependencies) — a metric class not currently in `sespy/network.py`.

**Village Tank Cascade.** Uses the identical centrality trio SESPy computes (degree, betweenness, eigenvector) → validation. Also demonstrates fuzzy cognitive mapping (FCM) as an edge-weighting scheme, an alternative to the KUMU Strong-negative→Strong-positive recoding currently used on import.

**Land-use leverage.** Indicator-based leverage-point identification; relevant to how leverage results are *labelled/typed* rather than to the math.

**Hybrid ML resilience model.** Powerful but heavy; conflicts with the MarineSABRES "simple SES" goal. Benchmark-only, not a core module.

**PAI framework.** Conceptual recursive-feedback governance model; input for the AI-ISA wizard, not code.

## Roadmap items (SESPy)

### High
- **`sespy/network.py` — uncertainty-aware leverage & loop scoring.** Propagate edge `strength`/`confidence` through the leverage composite and loop-polarity classification via the existing Monte Carlo, returning distributions/CIs instead of point values. *Motivated by:* D2D (10.1186/s12916-026-04971-0). *Effort:* moderate (reuses existing code). *Issue:* yes — see `proposed-issues.md`.

### Medium
- **`sespy/network.py` — social-ecological "fit" metric.** Add a fit/alignment diagnostic between social and ecological subgraphs. *Motivated by:* Dianchi Lake (10.1016/j.eiar.2026.108522). *Effort:* moderate. *Issue:* yes.
- **Import path — FCM edge weights.** Accept fuzzy-cognitive-map weights as an alternative to KUMU recoding; centrality outputs already align. *Motivated by:* Village Tank Cascade (10.3390/su18126151). *Effort:* moderate.
- **Leverage-point typology tagging (shallow→deep).** Tag leverage outputs with a Meadows-style depth class. *Motivated by:* land-use leverage (10.1016/j.ecolind.2026.115042). *Effort:* quick.

### Low
- **Benchmark only:** keep the hybrid ML residual model as an optional comparison, not a core module (simple-SES tension). 10.1016/j.scs.2026.107539. *Effort:* optional.

**One-line takeaway (SESPy):** add Monte-Carlo uncertainty to leverage/loop scoring (D2D) — highest-value change this week.
