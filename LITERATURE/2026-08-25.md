## Implications for SESPy

**D2D/Uleman et al. (BMC Medicine 2026) — canonical source paper for SESPy's shipped uncertainty feature.** Uleman et al. present the Diagrams-to-Dynamics (D2D) method: CLDs are converted to exploratory system dynamics models by treating each edge as a unit signed interaction and running Monte Carlo simulations over the structural uncertainty space (edge presence and sign). The method compares favourably against static network centrality (betweenness, eigenvector, PageRank) for identifying leverage points, while also producing per-node CIs and guidance for data collection. The paper ships an open-source Python package and a web-based application. This is directly the methodology underlying SESPy's `uncertainty_scores()` (closed issue #4, merged `fa9e212`). No feature gap is identified; the paper provides the methodological citation for SESPy's existing implementation. One secondary note: the D2D paper is health-science focused (BMC Medicine), demonstrating the method's generality beyond SES — a potential citation for SESPy documentation.

**FCM activation function paper (Revay et al., Neural Computing and Applications 2026) — low SESPy impact.** Revay et al. show that the choice of sigmoid vs. hyperbolic-tangent vs. step activation function in FCM simulations significantly affects steady-state outcomes, and provide a decision framework: the activation function should be chosen to match the domain's dynamics (bounded-binary vs. continuous vs. bipolar). SESPy currently imports FCM edge weights (closed issue #2) but does not expose the activation function as a user parameter when FCM weights are used in simulation. This suggests a low-priority enhancement: expose `activation_fn` as a selectable parameter on the FCM simulation path. However, SESPy's primary modelling paradigm is signed CLDs, not iterative FCM activation-update cycles; the impact is limited to the FCM import use-case.

**Adjusted Loop Centrality / ALC (Environmental Science & Policy, January 2025) — deferred Medium candidate.** A methodology paper on identifying leverage points in a Food–Energy–Water Nexus CLD introduces the *Adjusted Loop Centrality* (ALC) metric, which weights a node's importance by the loops it participates in (as a function of loop strength and the node's role as initiator vs. reinforcer), rather than treating each node independently via standard betweenness/eigenvector/PageRank. This is conceptually distinct from SESPy's existing `leverage_scores()`, which computes a composite of z(betweenness)+z(eigenvector)+z(PageRank) over the full graph without loop-membership weighting. ALC would produce a *loop-informed* leverage ranking complementing — or stress-testing — the existing composite. The algorithm is bounded and well-defined: it requires the loop set (which SESPy already computes via `find_loops()`), per-node loop membership, and an ALC formula. This is a genuine Medium extension not previously filed. **Deferred to a future week** because the paper is from January 2025 (outside this week's scan window) and because open issues #20–21 (diffusion chart/ranking stability) should close before adding another leverage metric variant.
