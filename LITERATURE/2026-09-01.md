## Implications for SESPy

**1. Chávez et al. — CLD for SES vulnerability (small-scale farming)**
VALIDATES SESPy's core use case: CLD-based SES vulnerability mapping is active peer-reviewed practice in agricultural systems. Full abstract unavailable; no deeper analysis possible.
**Verdict: VALIDATE.** No feature gap.

**2. Boyall et al. — NbCS amplification dynamics**
Their typology of simultaneous / sequential / regressive propagation dynamics is exactly what SESPy's planned `token_diffusion()` (open #17) would compute (reach and speed from an intervention node) and what `loop_dominance()` (open #22) would characterise (which feedback loop governs behaviour at each phase). The paper provides a conceptual vocabulary for interpreting those outputs and supporting the "amplification" framing in future documentation.
**Verdict: VALIDATE roadmap** items #17 and #22. No new gap.

**3. Heredia et al. — 38-year coupled human-natural system**
Polycentric governance (multiple R/M-typed nodes with no single dominant actor) and adaptive governance (adjusting R/M weights over time) are empirically linked to long-term resilience. SESPy's `governance_gap()` (#13) and `governance_actor_influence()` (#14) address the structural side. This paper motivates a polycentric diversity index (Shannon entropy over governance influence scores) as an incremental extension of #14 rather than a new feature.
**Verdict: VALIDATE** #13/#14. No new issue.

**4. Pinheiro et al. — HyperMod, tripartite network hypermodules**
This is the strongest methodological hit this week. SES networks are inherently multipartite: at minimum they carry an ecological tier (S/I/P nodes), a social tier (D/A nodes), and a governance tier (R/M nodes) under DAPSI(W)R(M) typing. Current SESPy metrics assess cross-tier *coupling density* (`social_ecological_fit`) or *gaps* (`governance_gap`). HyperMod asks a different question: which nodes across all tiers form cohesive multi-tier modules — SES subsystems where ecological processes, social activities, and governance actors are all densely interconnected? These modules are the SES analogue of the hypermodules Pinheiro et al. identify in plant–herbivore–parasitoid chains. SESPy already holds the tier partition (DAPSI(W)R(M) types), the graph, and NetworkX community detection. The adaptation requires bipartite projections for each tier pair and module-congruence logic across projections.
**Verdict: EXTEND — new Medium item. GitHub issue: yes.**

**5. Kraehling — KL divergence early warning of network collapse**
Open issue #15 (`cascade_vulnerability()`) simulates sequential node removal and reports the structural-integrity drop curve. Kraehling's signal fires *before* that drop: KL divergence between adjacent degree distributions accelerates toward the percolation threshold, providing a pre-threshold early-warning step. This is a complementary output for the same plot.
**Verdict: EXTEND** open issue #15. No new issue — add as a note on #15.

**6. Abdollahipour & Taheri — Fuzzy centrality**
SESPy's `uncertainty_scores()` already addresses edge-weight uncertainty via Monte Carlo structural perturbation. Fuzzy centrality uses a different formalism (membership functions on edge weights) and requires well-characterised fuzzy membership functions that stakeholders rarely supply. Low practical benefit given the "simple SES" goal.
**Verdict: NON-ACTIONABLE.** Interesting conceptual parallel; no issue.

### MEDIUM

**M1 — Cross-tier hypermodule detection in `sespy/network.py`**
*Target:* `sespy/network.py`, new function `hypermodule_detection(g)`.
*What to add:* using the DAPSI(W)R(M) tier partition (ecological: S/I/P; social: D/A; governance: R/M), build per-tier-pair bipartite projections, detect community modules within each bipartite sub-graph, and report cross-tier module congruence — nodes that co-occur in the same module across at least two tier projections (the SES-network hypermodule). Return a DataFrame of `{node, tier, hypermodule_id, within_tier_degree, cross_tier_degree}` and a hypermodularity score. Expose in the Network Metrics module as a collapsible "SES Subsystem Modules" section.
*Motivating paper:* [10.1098/rspb.2026.1348](https://doi.org/10.1098/rspb.2026.1348)
*Effort:* Moderate. Reuses existing DAPSI(W)R(M) partition; bipartite projection and community detection available in NetworkX.
*Issue:* **yes.**

**M2 — KL divergence early-warning step for cascade vulnerability (extend #15)**
*Target:* `sespy/network.py`, extend `cascade_vulnerability()`.
*What to add:* alongside the existing LCCF curve, compute smoothed KL divergence between successive degree distributions at each removal step and report the departure point — a structural precursor signal that predates the LCCF threshold.
*Motivating paper:* [10.21203/rs.3.rs-9204974/v3](https://doi.org/10.21203/rs.3.rs-9204974/v3)
*Effort:* Quick–moderate. *Issue:* no — extend open issue #15 directly.
