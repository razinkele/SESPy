## Implications for SESPy

**FCM dynamic explainability via causal and temporal analysis (key paper).** An Applied Soft Computing paper proposes a dynamic explainability method for FCMs that traces *causal pathways* — directed chains of influence between nodes — annotated by their temporal evolution and compound causal polarity. SESPy's existing analysis covers feedback loops (closed cycles, `find_loops()`), node-level centrality (`leverage_scores()`), and Monte Carlo uncertainty (`uncertainty_scores()`), but does not enumerate *open* directed causal paths between a selected pair of nodes. A `causal_paths(g, source, target)` function — enumerating all simple directed paths and computing each path's compound polarity (product of edge signs along the path) — would directly answer a practitioner's question: "Through which causal chains does variable A influence variable B, and are those chains net-positive or net-negative?" This is computationally tractable via NetworkX's `all_simple_paths`, distinct from all existing features and open issues (#1–#15), and consistent with SESPy's static qualitative scope (no temporal simulation required — only sign arithmetic along paths). Motivating paper's temporal/dynamic layer is outside SESPy's scope; the static causal chain aspect is fully within it.

**CLD construction for proenvironmental behaviour.** A Systems Research paper applies CLD methodology to identify and structure the factors driving pro-environmental behaviour, using a systematic factor-identification process before CLD construction. Relevant as a methodology reference validating SESPy's CLD-first modelling workflow. No algorithmic extension — SESPy processes CLDs after construction, not during the factor-identification step.

**Policy robustness and uncertainty in model-based decision support.** A paper on uncertainty quantification in model-based policy support for energy-transition decisions. Confirms that uncertainty propagation in qualitative policy models is a live methodological concern across domains. Validates SESPy's shipped `uncertainty_scores` D2D Monte Carlo feature; no distinct new extension beyond what is shipped.

**FCM participatory approach in agricultural living lab.** A Journal of Open Innovation paper applies FCM in a participatory action-research setting (Sicilian living lab, agricultural twin transition). Demonstrates FCM as a stakeholder-elicitation tool with iterative refinement — consistent with SESPy's multi-rater QSEM workflow (shipped C1–C3) and FCM import (#2, closed). Validates existing functionality; no new feature.

**CLD education and systems thinking transfer.** A Thinking Skills and Creativity study explores undergraduate ability to construct and transfer CLD-based models of global warming. Pedagogically relevant but no computational/software implication for SESPy.

### Medium
- **NEW — `sespy/network.py` — causal path tracer.** Add `causal_paths(g, source, target, max_length=None)` enumerating all simple directed paths between a source and target node in the CLD using NetworkX `all_simple_paths`, and for each path computing its compound polarity (product of edge signs) and path length. Returns a DataFrame with columns `path` (node list), `length`, `compound_polarity` ('+', '−', or '0' if any edge is unsigned), sortable by length. Expose in a new "Causal Pathways" collapsible section in the Network Metrics module with a node-pair selector. *Motivated by:* A dynamic explainability method for fuzzy cognitive maps based on causal and temporal evolution analysis (10.1016/j.asoc.2026.115925). Opened as razinkele/SESPy#16 (2026-07-28).
