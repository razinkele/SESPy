## Implications for SESPy

**Network cascading effects and ecological vulnerability thresholds (key paper).** An ERL paper demonstrates that sequential node-removal cascade analysis of ecological networks reveals nonlinear vulnerability thresholds — sharp discontinuities where the loss of a single node triggers disproportionate degradation of network integrity — that are invisible to individual node centrality metrics evaluated in isolation. SESPy's leverage scores (z-score composite of betweenness, eigenvector, PageRank) identify which nodes are structurally important, but they do so by examining each node independently and linearly. Cascade simulation — sequentially removing nodes in leverage-rank order and re-measuring network connectivity and loop structure — would reveal whether the SESPy-identified top leverage points also coincide with cascade threshold nodes, and whether there are "hidden" threshold nodes that rank low on linear centrality but trigger outsized cascade effects. This is a genuinely novel, computationally tractable extension of `sespy/network.py`, distinct from all existing issues and shipped features. Caveat: full paper not accessible via proxy; computational approach inferred from title and ERL scope.

**Pollinator network collapse under stochastic fluctuations.** A Proc. Royal Soc. B study shows that network structure (topology) determines whether random demographic fluctuations trigger population collapse. Directly validates SESPy's D2D Monte Carlo uncertainty scoring (shipped in `uncertainty_scores`, `fa9e212`): the same principle — stochastic perturbations interact with network structure to produce non-trivial outcome distributions — underpins SESPy's edge sign-flip / weight-drop sampling. This paper does not suggest a distinct new feature beyond what is already shipped; it strengthens the conceptual case for SESPy's existing uncertainty module.

**Three Gorges SES multi-scale pathways.** A landscape-ecology study applying multi-scale SES analysis to integrated protection and restoration. Uses SES framing (pressures, states, responses) consistent with DAPSIWR(M) but in a terrestrial/freshwater mountain context with spatial GIS components absent from SESPy. Validates the SES framework SESPy implements; no algorithmic extension.

**AI-generated FCMs with Bayesian de-chunking.** A book chapter proposes using LLM agents to generate FCM structures from text, followed by Bayesian inference to aggregate and refine ("de-chunk") them. SESPy already imports FCM edge weights (#2, closed); this paper proposes an upstream AI-generation step. Interesting, but importing AI-generated FCMs is outside SESPy's "simple SES / practitioner-driven" scope — it would require LLM integration and introduce model reliability questions.

**Generalized feedforward loop model.** A mathematical study of feedforward loop (FFL) motifs in biological and other networks. FFLs are directed 3-node motifs (A→B, A→C, B→C) distinct from the reinforcing/balancing feedback cycles SESPy analyzes via loop detection. Theoretically, SESPy could enumerate FFLs alongside feedback loops; in practice, the DAPSIWR(M) modelling tradition does not distinguish FFLs, and adding motif enumeration would extend scope substantially. Non-actionable at this time.

### Medium
- **NEW — `sespy/network.py` — cascade vulnerability indicator.** Add `cascade_vulnerability(g)` performing sequential node removal in leverage-rank order and re-measuring network integrity (largest connected component fraction, surviving feedback loop count) at each step. Returns a DataFrame of metrics per removal step plus a `cascade_threshold_node` — the node whose removal triggers the largest relative integrity drop. Complements `leverage_scores()` (which ranks by linear centrality) with a nonlinear structural-resilience perspective, as motivated by the ERL cascading-effects paper. Expose as an optional table/plot in the Network Metrics module. *Motivated by:* Network cascading effects reveal thresholds and nonlinearity in ecological vulnerability (10.1088/1748-9326/ae83cb). Opened as razinkele/SESPy#15 (2026-07-21).
