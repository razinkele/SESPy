## Implications for SESPy

**QSEM framework paper (methodological context for shipped feature).** Brown, Radley & Hulme (2025) introduce the QSEM as a semi-quantitative framework for systematically analysing CLDs within participatory system dynamics: (i) System Factor Classification via matrix-based connection scoring, (ii) Loops of Interest identification, and (iii) Archetype Identification and Analysis. This is the canonical source paper for the import format SESPy already supports (closed issue #7). The paper's emphasis on *archetype detection* — identifying system archetypes (Limits to Growth, Shifting the Burden, Tragedy of the Commons, etc.) within a CLD — is not currently surfaced by SESPy after import. SESPy extracts QSEM edge weights and signed structure but does not classify the resulting feedback loops against known archetypes. This is a potential Medium-priority extension; however, archetype detection requires defining canonical signed-loop patterns and mapping detected loops against them — a bounded algorithmic task that is distinct from QSEM import itself. Worth filing only once the causal-paths and cascade features (open #20–21 nearing resolution) stabilise. Noting here for a future week.

**Socioecological network robustness via bipartite species-loss simulation.** Stanworth et al. (2025) simulate sequential species loss in a bipartite socioecological network (species × ecosystem-service users) and measure the point at which each service collapses — analogous in spirit to SESPy's cascade vulnerability indicator (closed #15), but applied to mutualistic bipartite interaction networks rather than CLDs. SESPy does not model bipartite ecological networks; its graphs are directed signed CLDs with typed nodes. The paper reinforces the importance of SESPy's cascade vulnerability indicator and the role of interaction rewiring (network adaptability) in buffering collapse. No computational extension is warranted for SESPy's scope.
