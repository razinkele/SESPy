**Closest-to-actionable item:** Clifford Astbury et al. (BMC Global Public Health 2026) validates the group model building + CLD + systems archetypes workflow SESPy supports. The paper's multi-country, multi-stakeholder GMB process (39 participants, three workshop rounds, iterative stakeholder refinement of CLDs) is directly analogous to SESPy's intended use case. It does not propose a computational extension, but it confirms that the archetype identification step (which SESPy does not yet expose in the UI beyond loop classification) is useful to practitioners. If a future UI pass is planned for the Loop Analysis module, surfacing named Senge/Meadows archetypes (e.g. "balancing process with delay", "fixes that fail") as an interpretive overlay on detected loop structures could align with practitioner workflows. This is a LOW / future consideration, not an immediate issue.
