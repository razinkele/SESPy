## Implications for SESPy

**SENA governance gaps in MPAs (key paper).** Introduces governance gap detection as a first-class social-ecological network analysis (SENA) diagnostic — distinguishing *ecological nodes with no governance actor coverage* from *governance actors with no ecological target*. This is conceptually distinct from the shipped `social_ecological_fit` metric (which measures cross-boundary coupling density): SE fit scores how well existing links align; governance gap detection finds nodes that are entirely unlinked. SESPy already has the necessary ingredients — DAPSIWR(M) node typing, a NetworkX graph, and the existing `subsystem()` partition — so a `governance_gap(g)` function is a natural, low-risk extension. Strong case for opening an issue.

**SE fit in blue-green infrastructure.** Applies SE fit to urban BGI by combining species distribution models (SDMs) with actor-governance survey data, finding that blue-urban-green areas exhibit systematic SE misfit while blue-rural-green areas do not. Validates the shipped `social_ecological_fit` feature (closes GitHub #1). The biotic SDM dimension requires observational species occurrence data SESPy does not hold; not actionable within the simple-SES scope.

**Water governance CLD (Qarranqu Basin preprint).** Applies a CLD-plus-leverage-point workflow to diagnose governance complexity in an Iranian watershed, mapping reinforcing and balancing feedback loops across institutional actors. Validates SESPy's core CLD + `leverage_scores` + `feedback_loops`/`loop_polarity` pipeline in an institutional governance domain. Conceptual validation only; no algorithmic extension.

**Informal settlements systems thinking.** CLD-based systems-thinking framework applied to urban-planning sustainability. Domain (urban informal settlements) does not align with MarineSABRES marine SES focus; no actionable SESPy contribution.

**FCM + PROMETHEE-II (supply chain).** Combines fuzzy cognitive mapping with PROMETHEE-II MCDM for supply chain disruption. Validates FCM as an edge-weighting tool (shipped #2 closed). The MCDM integration is operations-research specific; not applicable to SESPy's qualitative SES model.
